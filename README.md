# Brew Haven

A premium, responsive coffee shop website for Brew Haven, built with HTML, CSS, and vanilla JavaScript.

## Overview

This project features a warm, modern coffee brand aesthetic with sections for:
- navigation and call-to-action hero
- product highlights and story
- menu cards with category filtering
- special offer banner
- testimonials
- gallery
- contact form with validation
- cart/order interaction and theme toggle

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome

## Project Structure

```text
coffee-shop-website/
├── index.html
├── style.css
├── script.js
├── README.md
```

## Run locally

Open `index.html` directly in a browser.

You can also serve the project with any local static server of your choice if needed.

## Features

- Sticky navigation with mobile menu
- Light/dark mode toggle saved in localStorage
- Menu filtering by category
- Order cart with quantity updates and totals
- Testimonial slider
- Contact form validation and success message
- Responsive layout for desktop, tablet, and mobile

## Brand

- Name: Brew Haven
- Tagline: Crafted with passion. Served with warmth.

## Notes

This is a static front-end project and does not include a real backend or payment processing.
